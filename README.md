# ตู้ถ่ายรูป 4 ช็อต (เวอร์ชัน 1)

ใช้งานได้ที่ **https://polaris-jk.github.io/Photobooth/**

เว็บแอพถ่ายรูปแบบตู้สติกเกอร์ ทั้งแอพอยู่ในไฟล์เดียวคือ `index.html` ทำงานในเบราว์เซอร์ทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องมีที่เก็บไฟล์ และไม่มีค่าใช้จ่าย

## ทำอะไรได้บ้าง

- ถ่ายต่อกัน 4 ใบ นับถอยหลังได้ 3 / 5 / 10 วินาที (กดเลือกในแอพ)
- ฟิลเตอร์ สี / ขาวดำ (เลือกได้ก่อนถ่าย และเปลี่ยนได้อีกในหน้าผลลัพธ์)
- แถบรูปเป็นไฟล์ JPG ขนาด 1200×3600 px (เท่ากับ 2×6 นิ้ว พิมพ์ได้)
- คลิปเป็นแถบที่ขยับได้ (MP4): แต่ละช่องเล่น 2 วินาทีสุดท้ายก่อนกดชัตเตอร์ วน 3 รอบ ยาวประมาณ 6 วินาที ไม่มีเสียง
- เลือกสีกรอบ ขาว / ดำ / ชมพู / ครีม ก่อนบันทึก
- ปุ่มบันทึกลงเครื่อง
  - iPhone/iPad: จะมีเมนูเด้งขึ้นมา ให้กด "บันทึกภาพ" หรือ "บันทึกวิดีโอ" ไฟล์จะเข้าแอพรูปภาพ
  - Android และคอม: ไฟล์ลงโฟลเดอร์ดาวน์โหลด

## อัปเดตเวอร์ชันใหม่

1. เปิด https://github.com/Polaris-jk/Photobooth
2. กด Add file > Upload files ลาก `index.html` ไฟล์ใหม่ลงไปทับของเดิม แล้วกด Commit changes
3. รอ 1–2 นาที แล้วรีเฟรชหน้าเว็บ

ถ้าแก้นิดเดียว เช่น ข้อความท้ายแถบ ให้เปิด `index.html` ในหน้า repo กดไอคอนดินสอ แก้แล้วกด Commit changes ได้เลย

GitHub Pages ตั้งไว้ที่ Settings > Pages: Source = Deploy from a branch, Branch = `main` และ `/ (root)`

## ปรับแต่ง

เปิด `index.html` แล้วหา `const CONFIG` (อยู่ต้นส่วน `<script>`) แก้ค่าได้โดยไม่ต้องแตะส่วนอื่น

| ค่า | ใช้ทำอะไร | ค่าเริ่มต้น |
|---|---|---|
| `title` | ข้อความท้ายแถบ เช่น ชื่องานหรือชื่อร้าน (พิมพ์ไทยได้) | `'Photobooth'` |
| `timers` / `defaultTimer` | ตัวเลือกนับถอยหลัง และค่าที่เลือกไว้ตอนเปิดครั้งแรก | `[3, 5, 10]` / `3` |
| `liveSeconds` | ช่วงที่ขยับในคลิป กี่วินาทีก่อนชัตเตอร์ | `2` |
| `clipLoops` | ไฟล์คลิปวนกี่รอบ | `3` |
| `frames` | รายการสีกรอบ (`bg` สีกรอบ, `fg` สีตัวหนังสือ) เพิ่มหรือลบได้ | ขาว ดำ ชมพู ครีม |
| `sound` | เสียงบี๊บนับถอยหลังและเสียงชัตเตอร์ ใส่ `false` เพื่อปิด | `true` |

## เบราว์เซอร์ที่ใช้ได้

- iPhone/iPad: Safari บน iOS 15 ขึ้นไป
- Android: Chrome
- คอม: Chrome, Edge, Safari (ถ้าใช้ Firefox คลิปจะเป็นไฟล์ .webm)
- ต้องเปิดผ่านลิงก์ https กล้องถึงจะทำงาน (GitHub Pages เป็น https อยู่แล้ว) ถ้าดับเบิลคลิกเปิดไฟล์ในเครื่องตรงๆ กล้องอาจไม่ทำงาน
- ถ้าเปิดลิงก์จาก LINE แอพจะพาไปเปิดในเบราว์เซอร์ให้เอง ถ้าเปิดจาก Facebook หรือ Instagram ให้กด ⋯ แล้วเลือกเปิดในเบราว์เซอร์

## ความเป็นส่วนตัว

รูปและคลิปสร้างในเครื่องของคนที่ถ่ายทั้งหมด ไม่มีการอัปโหลดไปที่ไหน สิ่งเดียวที่โหลดจากข้างนอกคือฟอนต์จาก Google Fonts

## ทดสอบบนคอมตัวเอง (ไม่จำเป็น)

ในโฟลเดอร์ที่มี `index.html` ให้รัน

```
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000` บนคอมเครื่องเดียวกัน
