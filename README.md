# Tu.Photobooth (เวอร์ชัน 2.4)

ใช้งานได้ที่ **https://tuphotobooth.pages.dev/**

ลิงก์เดิม https://polaris-jk.github.io/Photobooth/ ยังใช้ได้ ทั้งสองลิงก์อัปเดตพร้อมกันทุกครั้งที่ push ขึ้น `main` (Cloudflare Pages ดึงจาก repo นี้ ตั้งค่า: Framework None, Build command ว่าง, Build output `/`)

ตู้ถ่ายรูปบนเว็บแบบตู้สติกเกอร์ ทำงานในเบราว์เซอร์ทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องมีที่เก็บไฟล์ และไม่มีค่าใช้จ่าย

## ทำอะไรได้บ้าง

- ถ่ายต่อกัน 1, 2, 3, 4, 6 หรือ 9 รูป นับถอยหลัง 3 / 5 / 10 วินาที (แตะปุ่มนาฬิกาข้างปุ่มถ่ายเพื่อสลับ)
- รูปแบบเฟรม
  - เดี่ยว: แบบโพลารอยด์ สัดส่วน 4:5 ข้อความใต้รูปเป็นลายมือ
  - แถบ: 2, 3 หรือ 4 รูปเรียงลง
  - แถบคู่: 2 แถบเหมือนกันในแผ่นเดียว มีเส้นประให้ตัดแบ่งเพื่อน
  - แนวนอน: 2 รูปข้างกันในการ์ดแนวนอน
  - ใหญ่ + เล็ก: รูปแรกใหญ่ด้านบน อีก 2 หรือ 3 รูปเรียงด้านล่าง
  - ตาราง: 2×2 (4 รูป), 2×3 (6 รูป), 3×3 (9 รูป)
- ขอบกรอบเลือกได้ 4 แบบ: ไม่มี (รูปชิดกัน), บาง, ปกติ, หนา อยู่ในแท็บ "กรอบ" เปลี่ยนหลังถ่ายได้ด้วย
- ถ่ายคู่: ใส่รูปคนที่ไดคัทแล้ว (พื้นใส) ช่องละ 1 รูป วางชิดขวาล่าง แตะเพื่อสลับซ้ายขวา รูปเก็บไว้ในเครื่องนั้นเท่านั้น (ดูหัวข้อ "ถ่ายคู่")
- เรืองแสง: เปลี่ยนสีพื้นจอในตู้ให้ส่องหน้าเป็นสีนั้น มีสีให้เลือก 11 สี เลือกสีเองได้ และปรับความเข้มได้ ถ้าเปิดแฟลชกล้องหน้า จอจะสว่างเป็นสีที่เลือกตอนกดชัตเตอร์
- ฟิลเตอร์ 13 แบบ: ปกติ, Fresh, Peach, Honey, Mint, Dream, 90s, Instant, ฟิล์มสี, ซีเปีย, ขาวดำ, ขาวดำฟิล์ม, Noir (ภาพสดในกล้องเห็นฟิลเตอร์ก่อนถ่าย ปุ่มเลือกฟิลเตอร์ใช้รูปตัวอย่างรูปเดียวกันทุกปุ่ม จะได้เทียบกันง่าย)
- กรอบ: สีพื้น 10 สี, ลายธีมคริสต์มาส 16 แบบ (เกล็ดหิมะ ต้นคริสต์มาส ลูกบอลประดับ ใบฮอลลี่ ดาวทอง กล่องของขวัญ ไฟประดับ สก็อตคริสต์มาส ไม้เท้าลูกกวาด) และลายทั่วไป 11 แบบ
- ก่อนถ่าย จอกล้องโชว์ทั้งเฟรมพร้อมภาพสดในทุกช่อง จะได้เห็นหน้าตารูปที่จะได้ พอกดถ่ายจะกลับเป็นจอใหญ่ช่องเดียว
- แฟลช: กล้องหน้าใช้จอขาวทั้งจอส่องหน้าตอนกดชัตเตอร์ กล้องหลังเปิดไฟแฟลชค้างไว้ระหว่างถ่าย ถ้าเครื่องรองรับ (เว็บสั่งเพิ่มความสว่างจอเองไม่ได้ ผู้ใช้ต้องเร่งเอง)
- เลือกทุกอย่างได้ในหน้ากล้อง แล้วยังเปลี่ยนฟิลเตอร์ กรอบ และรูปแบบที่สัดส่วนเดียวกัน (เช่น แถบ ↔ แถบคู่) ได้อีกในหน้าผลลัพธ์
- ปุ่ม "อัลบั้ม" เลือกรูปที่มีอยู่แล้วมาทำเป็นแถบได้ ถ้าเลือกมาน้อยกว่าจำนวนช่อง แอพจะเปลี่ยนรูปแบบให้พอดีเอง
- ไฟล์ที่ได้: รูป JPG และคลิป MP4 ที่แต่ละช่องขยับ 2 วินาทีก่อนกดชัตเตอร์ วน 3 รอบ ยาวประมาณ 6 วินาที (คลิปมีเฉพาะตอนถ่ายจากกล้อง)
- บันทึกลงเครื่อง
  - iPhone/iPad: มีเมนูเด้งขึ้นมา ให้กด "บันทึกภาพ" หรือ "บันทึกวิดีโอ" ไฟล์จะเข้าแอพรูปภาพ
  - Android และคอม: ไฟล์ลงโฟลเดอร์ดาวน์โหลด

## ขนาดไฟล์

| รูปแบบ | รูป (JPG) | คลิป (MP4) |
|---|---|---|
| เดี่ยว | 1200×1500 | 600×750 |
| แถบ 2 / 3 / 4 รูป | 1200×1980 / 1200×2792 / 1200×3600 | ครึ่งหนึ่งของรูป |
| แถบคู่ 2 / 3 / 4 รูป | 2400×1980 / 2400×2792 / 2400×3600 | ครึ่งหนึ่งของรูป |
| ตาราง 2×2 | 2400×3600 | 1200×1800 |
| แนวนอน 2 รูป | 2400×1680 | 1200×840 |
| ใหญ่ + เล็ก 3 / 4 รูป | 2360×2980 / 2400×2740 | ครึ่งหนึ่งของรูป |
| ตาราง 2×3 / 3×3 | 2400×3540 / 2400×2680 | ครึ่งหนึ่งของรูป |

ขนาดในตารางเป็นขอบแบบปกติ ถ้าเลือกขอบบางหรือไม่มีขอบ รูปจะเล็กลงเล็กน้อย ถ้าเลือกขอบหนาจะใหญ่ขึ้น (ช่องรูปขนาดเท่าเดิม)

แถบ 4 รูป = 2×6 นิ้ว, แถบคู่ 4 รูปและตาราง 2×2 = 4×6 นิ้ว ที่ 600 dpi พิมพ์ได้ทันที

## เพิ่มไอคอนลงหน้าจอโฮม

- iPhone/iPad: เปิดลิงก์ใน Safari กดปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" จะได้ไอคอน "ตู้" ลายมือบนการ์ดรูป ชื่อ Tu.Photobooth
- iPhone/iPad ไม่เปลี่ยนไอคอนที่เพิ่มไว้แล้วให้เอง คนที่เคยเพิ่มไว้ก่อนจะเห็นข้อความบอกครั้งเดียวว่าให้ลบไอคอนเดิมแล้วเพิ่มใหม่
- Android: เปิดใน Chrome กดเมนู ⋮ แล้วเลือก "เพิ่มลงในหน้าจอหลัก" หรือ "ติดตั้งแอพ"

## อัปเดตเวอร์ชันใหม่

1. เปลี่ยนเลข `APP_VERSION` ใน `index.html` และ `"version"` ใน `version.json` ให้เป็นเลขใหม่เดียวกัน เช่น `2.3.0`
2. เปิด https://github.com/Polaris-jk/Photobooth
3. กด Add file > Upload files ลากไฟล์ที่แก้แล้วลงไปทับของเดิม แล้วกด Commit changes
4. รอ 1–2 นาที คนที่เปิดแอพค้างไว้จะเห็นแถบ "มีเวอร์ชันใหม่แล้ว" ในเบราว์เซอร์เป็นปุ่ม รีเฟรช ส่วนคนที่เพิ่มไว้บนหน้าจอโฮมเป็นปุ่ม อัปเดต กดแล้วได้เวอร์ชันใหม่ทันที คนที่ใช้เวอร์ชันล่าสุดอยู่แล้วจะไม่เห็นอะไร
5. แถบนี้ไม่ขึ้นระหว่างถ่ายและตอนอยู่หน้ารูปที่ได้ รูปที่ยังไม่บันทึกจะไม่หาย

ถ้าเปลี่ยนไอคอน ให้เพิ่มเลข `ICON_VERSION` ใน `index.html` และเลข `?v=` หลังชื่อไฟล์ไอคอนใน `index.html` กับ `manifest.webmanifest` ด้วย

GitHub Pages ตั้งไว้ที่ Settings > Pages: Source = Deploy from a branch, Branch = `main` และ `/ (root)`

## ปรับแต่ง

เปิด `index.html` แล้วดูส่วนต้นของ `<script>`

| ส่วน | แก้อะไรได้ |
|---|---|
| `CONFIG` | ข้อความท้ายรูป (`title`), ตัวเลือกนับถอยหลัง, รูปแบบ/ฟิลเตอร์/กรอบ/ความหนาขอบเริ่มต้น (`defaultBorder`), รูปตัวอย่างฟิลเตอร์ (`filterSample`), ความยาวช่วงขยับ, จำนวนรอบของคลิป, เสียง, รหัส GoatCounter (`goatcounter`) |
| `LAYOUTS` | รายการรูปแบบเฟรม ลบตัวที่ไม่ใช้ออกได้ |
| `BORDERS` | ความหนาขอบ (`k` คูณกับขอบปกติ) |
| `GLOWS` | สีเรืองแสงที่ให้เลือก เพิ่มหรือเปลี่ยนสีได้ |
| `STYLES` | สีกรอบและลาย เพิ่มสีใหม่ได้ เช่น `{ id: 'mint', name: 'เขียวมินต์', kind: 'solid', bg: '#bfe5d6', ink: '#1f3d33' }` |
| `FILTERS` | ฟิลเตอร์ ปรับค่าความสว่าง คอนทราสต์ ความอิ่มสี เกรน และขอบมืดได้ |

## ถ่ายคู่

ให้คนในรูปดูเหมือนยืนถ่ายคู่กับอีกคน (แบบกรอบศิลปินของตู้ถ่ายรูป) ใช้รูปที่คุณมีสิทธิ์ใช้

1. ไดคัทรูปบน iPhone: เปิดรูปในแอพรูปภาพ กดค้างที่ตัวคนจนมีขอบเรืองแสง แล้วกด แชร์ → บันทึกภาพ จะได้รูปพื้นใสเก็บไว้ในแอพรูปภาพ
2. ในแอพ ไปที่แท็บ "ถ่ายคู่" กด + แล้วเลือกรูปเรียงตามช่อง 1, 2, 3, ... (แตะช่องว่างเพื่อใส่เฉพาะช่องนั้นก็ได้)
3. คนไดคัทจะอยู่ชิดขวาล่างของแต่ละช่อง แตะรูปในแถบ หรือแตะในจอตัวอย่าง เพื่อสลับไปซ้าย (กลับด้านให้หันเข้าหากัน) กด × เพื่อลบ ปุ่ม ปิด/เปิด ใช้ปิดชั่วคราวโดยไม่ลบรูป
4. ฟิลเตอร์ลงทั้งคนในกล้องและคนไดคัท รูปจากอัลบั้มก็ใส่คนไดคัทให้ด้วยถ้าเปิดถ่ายคู่อยู่

รูปไดคัทเก็บไว้ในเบราว์เซอร์ของเครื่องที่ใส่เท่านั้น (IndexedDB) ไม่ได้อัปโหลด ไม่อยู่ใน repo คนอื่นที่เปิดลิงก์จะไม่เห็น ถ้าเปิดผ่าน Safari แล้วไม่ได้เข้าเว็บหลายวัน iPhone อาจล้างข้อมูลเว็บรวมถึงรูปพวกนี้ ถ้าเพิ่มแอพไว้บนหน้าจอโฮมจะไม่โดนล้างแบบนี้

## ดูจำนวนคนใช้ (GoatCounter ฟรี)

เปิดอยู่แล้ว ดูตัวเลขได้ที่ https://tuphotobooth.goatcounter.com

ไม่ต้องมีหลังบ้านเอง ใช้ GoatCounter นับให้

1. สมัครที่ https://www.goatcounter.com/signup ตั้งรหัสเว็บ เช่น `tuphotobooth` (จะได้หน้า `tuphotobooth.goatcounter.com`)
2. ใน `index.html` ใส่รหัสนั้นที่ `CONFIG.goatcounter: 'tuphotobooth'`
3. อัปโหลดขึ้น GitHub แล้วเข้าไปดูตัวเลขที่หน้า GoatCounter ของตัวเอง

สิ่งที่นับ
- จำนวนคนเปิดเว็บ (นับอัตโนมัติ)
- `open-camera` เปิดกล้อง
- `shoot-strip4`, `shoot-single` ฯลฯ ถ่ายเสร็จหนึ่งชุด แยกตามรูปแบบ
- `album-...` ทำรูปจากอัลบั้ม
- `save-photo` และ `save-clip` กดบันทึกรูปและคลิป
- `pair-add` ใส่รูปถ่ายคู่, `shoot-pair` ถ่ายเสร็จโดยเปิดถ่ายคู่

ถ้าเว้น `goatcounter` ว่างไว้ จะไม่มีการนับใดๆ

## เบราว์เซอร์ที่ใช้ได้

- iPhone/iPad: Safari บน iOS 15 ขึ้นไป
- Android: Chrome
- คอม: Chrome, Edge, Safari (ถ้าใช้ Firefox คลิปจะเป็นไฟล์ .webm)
- ฟิลเตอร์ใช้ WebGL ถ้าเครื่องไม่รองรับจะเหลือแค่ ปกติ กับ ขาวดำ
- ต้องเปิดผ่านลิงก์ https กล้องถึงจะทำงาน ถ้าดับเบิลคลิกเปิดไฟล์ในเครื่องตรงๆ กล้องอาจไม่ทำงาน
- ถ้าเปิดลิงก์จาก LINE แอพจะพาไปเปิดในเบราว์เซอร์ให้เอง ถ้าเปิดจาก Facebook หรือ Instagram ให้กด ⋯ แล้วเลือกเปิดในเบราว์เซอร์

## ความเป็นส่วนตัว

รูปและคลิปสร้างในเครื่องของคนที่ถ่ายทั้งหมด ไม่มีการอัปโหลดไปที่ไหน ที่โหลดจากข้างนอกมีฟอนต์จาก Google Fonts และ `version.json` ไว้เช็กเวอร์ชัน ถ้าเปิด GoatCounter จะส่งไปแค่ว่ามีการเปิดหน้าเว็บหรือกดปุ่มไหน ไม่มีรูป ไม่มีคุกกี้ รูปไดคัทในโหมดถ่ายคู่ก็อยู่แค่ในเครื่อง
